# Concept art de entidades

Primera dirección visual para los nuevos modelos de **Sorken**, **Arbmos** y **Veleth**.

- `sorken-concept-v1.png`: entidad principal; ángel quebrado, máscara funeraria, halo vertebral y alas vestigiales.
- `arbmos-concept-v1.png`: alucinación de cordura; silueta negra semitransparente y ojos blancos.
- `arbmos-concept-v2.png`: dirección seleccionada para Arbmos; criatura oscura de escala doméstica (aprox. 2 m), con torso abierto y múltiples ojos orientados al jugador.
- `veleth-concept-v1.png`: consecuencia de perder el libro; aberración-relicario con máscaras y alas esqueléticas.
- `veleth-concept-v2.png`: dirección seleccionada para Veleth; cuerpo angelical de sombra y rostro marfil inhumano, con múltiples ojos, mandíbula vertical y halo fracturado.
- `veleth-concept-v3.png`: rediseño alternativo; rostro radial marfil de tres ojos, boca-abismo circular y halo negro de espinas.
- `veleth-concept-v4.png`: dirección religiosa profanada; rostro de estatua sacra con rasgos desplazados lateralmente, halo gótico y lágrimas negras.
- `veleth-concept-v5.png`: rostro completamente irreconocible, descompuesto en estratos desplazados de marfil bajo un halo gótico.
- `veleth-concept-v6.png`: cabeza totalmente blanca y sin facciones, formada por estratos desplazados y envuelta en una fina malla dorada.

Las imágenes se concibieron como referencias de dirección visual para una futura traducción a modelos 3D, no como vistas ortográficas definitivas.

## Set final

- `veleth-final-concept.png`: Veleth con cabeza blanca de malla dorada y alas oscuras plegadas contra el cuerpo.
- `arbmos-final-concept.png`: Arbmos de dos metros, torso de ojos y alas recogidas dentro de su silueta doméstica.
- `sorken-final-concept.png`: Sorken como entidad principal, con alas vestigiales discretas pegadas a la espalda.

Las alas del set final se redujeron deliberadamente para confundirse con sombras, cortinas, muebles y líneas arquitectónicas durante el juego AR.
